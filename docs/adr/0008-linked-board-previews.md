# 0008. Превью вложенной доски на карточке холста

Дата: 2026-11-01 · Статус: принято

## Контекст

Одинаковые значки вложенных досок не позволяют понять содержимое без перехода внутрь.
По запросу пользователя карточка должна показывать миниатюру, название, число карточек
и кнопку перехода, по предоставленному визуальному образцу.

## Решение

- Элемент `board` получает компонент миниатюры через необязательный
  `ElementRuntime.BoardPreview`. Реализация остаётся в `features/project` и повторно
  использует превью галереи. Зависимости «вверх» из elements не появляются.
- Превью загружает документ только при появлении на экране, подписывается на элементы
  и связи и обновляет миниатюру и счётчик при изменениях, включая удаление и отмену.
- Внутри миниатюры runtime не передаёт компонент превью: вложенные карточки показывают
  компактный значок с названием. Циклические ссылки между досками не вызывают рекурсии.
- Старые размеры и координаты карточек сохраняются; новое оформление помещается в них.
  Новые карточки крупнее, размер можно менять. Формат проекта и миграции не меняются.
- Миниатюра не принимает ввод, не меняет документ и не загружает сетевые превью.
  Кнопка перехода доступна мышью, касанием и клавиатурой; двойной щелчок остаётся.

## Проверка

Браузер: заполненные и пустые доски, изображения и текст, обновление счётчика и имени,
переход кнопкой и двойным щелчком, старые размеры, светлая/тёмная темы, мобильный экран.
`pnpm check`, сквозные сценарии и замер холста на 1000 карточках.
