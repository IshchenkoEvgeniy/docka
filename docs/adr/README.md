# Архитектурные решения (ADR)

Каждое решение, меняющее стек, слои, формат данных или структуру папок, записывается здесь
отдельным файлом `NNNN-короткое-название.md` до того, как меняется код.

Шаблон:

```markdown
# NNNN. Название

Дата: ГГГГ-ММ-ДД · Статус: принято | заменено NNNN

## Контекст
Какая проблема и какие ограничения.

## Решение
Что выбрали.

## Альтернативы
Что рассматривали и почему отказались.

## Последствия
Что становится проще, что сложнее, что нужно поменять.
```
