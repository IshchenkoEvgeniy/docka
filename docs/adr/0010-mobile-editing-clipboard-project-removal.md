# ADR 0010: мобильная правка, буфер изображений и удаление проекта

Статус: принято. Дата: 2026-11-01.

Текст на всех устройствах редактируется в карточке. При входе в правку на телефоне
камера показывает карточку в читаемом масштабе; правящийся элемент остаётся смонтирован.
Автоматического полноэкранного редактора больше нет. Завершение — кнопкой «Готово»
на панели или касанием пустого холста.

Системный буфер читается через порт `ClipboardReader`: текст и двоичные файлы.
Android читает ClipboardManager на UI-потоке только по явному нажатию «Вставить»;
изображения content:// передаются через мост с ограничением размера. Браузерный
адаптер использует Clipboard API. В событии paste файлы обрабатываются до текстового
редактора; обычный текст внутри редактора продолжает вставляться как текст.

Удаление проекта доступно на главном экране после подтверждения его названия.
Сценарий ждёт закрытия сессий проекта, повторно проверяет его id по метаданным и
удаляет именно его папку. Отмена подтверждения не меняет файлы. Избранное и внешние
пути очищаются только после успеха. Ошибка остаётся видна в диалоге.
Порт FileSystem получает удаление непустого относительного пути папки. Нативный
адаптер запрещает удаление корня и выход за открытый корень; тесты используют память
и временные папки. Резервные копии вне папки проекта сохраняются.

Формат документов и версия формата не меняются. Сборки приложения запускает пользователь;
в этой задаче выполняются проверки и тесты.
