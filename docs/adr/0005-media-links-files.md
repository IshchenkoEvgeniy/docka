# 0005. Остальные элементы: файлы любого типа, превью ссылок по сети, открытие в системе

Дата: 2026-10-31 · Статус: принято

## Контекст

Этап 5 добавляет таблицу, фигуры, ссылку, файл, видео/аудио и цвет (ТЗ, раздел 5). Таблица,
фигуры и цвет — обычные элементы. Остальным нужно то, чего в приложении не было:

- хранить в `assets/` не только картинки, но и любые файлы, видео и звук;
- получить превью ссылки (заголовок, описание, картинка, значок сайта) — единственный сетевой
  запрос, который разрешают ТЗ (раздел 10) и CLAUDE.md;
- открыть ссылку в браузере, а файл — в системной программе;
- показать PDF, видео и встроенный плеер (YouTube и др.) — это меняет CSP окна.

## Решение

1. **Файлы проекта.** `assets/<sha256>.<расширение>` для любого файла до 50 МБ (картинки — как
   раньше). Расширение берётся из типа MIME или из имени файла (латиница и цифры, до 5 символов),
   иначе `bin`. Файл по-прежнему неизменяем — конфликтов нет. Предел 50 МБ: на Android файл
   передаётся в Rust строкой base64 целиком.
2. **Превью ссылки** получает Rust (`net_fetch`): из WebView чужие сайты не читаются (CORS).
   Команда узкая: только `http`/`https`, только GET, тайм-аут 10 с, не больше 2 МБ ответа,
   до 5 перенаправлений. HTTP-клиент — `reqwest`, который уже есть в Tauri; TLS — `rustls` с
   `ring` и корневыми сертификатами Mozilla (`webpki-roots`): одинаково на Windows и Android,
   без системного верификатора, которому на Android нужна отдельная инициализация из Kotlin.
3. **Разбор HTML** (Open Graph, `<title>`, значок) — чистая функция `parseLinkMeta` в папке
   элемента (`src/elements/link/meta.ts`), без DOM, с тестами. Картинка превью и значок сайта скачиваются один раз и кладутся
   в `assets/`: превью работает офлайн и доезжает до телефона через Syncthing без повторного
   запроса. Запрос делается только при создании ссылки и по кнопке «Обновить превью».
4. **Встраивание** (YouTube, Vimeo, Figma, Google Docs/Sheets/Slides, Яндекс Музыка) —
   `iframe` по кнопке «Встроить» на карточке: пока пользователь не нажал, сторонний сайт
   ничего не загружает. Адрес встраивания строится из ссылки по белому списку
   (`embedUrl`); в CSP `frame-src` — только эти сайты и `blob:` (просмотр PDF).
5. **Открытие в системе** — свои команды Rust поверх `tauri-plugin-opener` (его права в
   capabilities не открываются для JS): `system_open_url` (только `http`/`https`) и
   `system_open_file` (только файл внутри папки, открытой через `storage_open_root`).
   На Android файл открывается через мост `DoskaAndroid.openFile` (`FileProvider` и
   `ACTION_VIEW`), ссылка — через тот же `system_open_url`.
6. **Данные из сети** записываются без шага отмены (`fillElementData`, метка `FETCHED_ORIGIN`):
   это не действие пользователя — «Отменить» сразу после вставки ссылки убирает саму ссылку.
   Что подтянуть, решает тип элемента (`enrich` в описании), доска о ссылках не знает.
7. **Просмотр на весь экран** стал общим: тип элемента может отдать компонент `Viewer`
   (картинка, PDF). Доска не знает, какой тип что показывает.
8. **CSP:** `media-src 'self' blob:` (видео и звук из `assets/`), `frame-src` — см. п. 4,
   `img-src` без изменений (картинки превью — из `assets/` через `blob:`).
9. **Вставка таблицы из Excel**: тип элемента может распознать вставленный текст
   (`fromPastedText`); таблица узнаёт текст с табуляциями. Доска перебирает типы, не зная их.

Новые элементы добавляются папками в `src/elements/` и строкой в реестре; холст не меняется.
Формат проекта не меняется (версия 2): старое приложение покажет новые элементы заглушкой
«элемент из более новой версии» и не испортит их.

## Альтернативы

- **`tauri-plugin-http`** (fetch из JS): тот же `reqwest`, но права на любые адреса пришлось бы
  открывать в capabilities для всего фронтенда. Своя узкая команда проще проверить.
- **Картинки превью по прямой ссылке** (`img-src https:`): каждое открытие доски ходило бы в
  сеть, а на телефоне без интернета превью не было бы. Отказались.
- **pdf.js** для превью PDF: +1–2 МБ к сборке. Взяли встроенный просмотр WebView в `iframe`;
  где его нет (Android WebView) — кнопка «Открыть в программе».

## Последствия

- Размер сборки растёт на `rustls`, `ring`, `webpki-roots` (~1–1,5 МБ); на Android `rustls`
  с `ring` уже был в Tauri.
- Встраивание и превью работают только с интернетом; без него карточка ссылки показывает адрес
  и сохранённое ранее превью.
- Открытие файла на Android и встраивание YouTube в WebView Tauri нужно проверить на устройстве:
  в среде ИИ нет Android SDK и окна WebView.
