# 0007. Экспорт PNG: отдельная DOM-доска без виртуализации

Дата: 2026-11-01 · Статус: принято

## Контекст

Шаг 7.1: PNG всей доски или выделения, масштаб 1–3×, прозрачный или цветной фон.
Снимок видимого холста непригоден: виртуализация скрывает карточки вне экрана,
а обзор рисует только контуры. Экспорт не должен менять камеру и данные проекта.

## Решение

- `features/export` получает снимки элементов, связей и интерфейс чтения `ElementRuntime`.
  В отдельном DOM-слое рендерятся полные карточки через реестр, без рамок выделения,
  редакторов и виртуализации. Колонки включают дочерние карточки; выбранная дочерняя
  карточка без колонки экспортируется отдельно. Сущности используют контекст проекта.
- Признак `ElementRuntime.exporting` включает статичные подписанные карточки медиа
  вместо системных плееров: экспорт не зависит от загрузки первого кадра видео.
- PNG создаёт `html-to-image`, библиотека из ТЗ. Зависимость загружается динамически
  только при экспорте. Ожидаются локальные файлы, изображения и шрифты; экспорт
  не загружает превью из сети. Отсутствующие файлы остаются подписанными заглушками.
- Размер рассчитывается в мировых координатах, независимо от камеры и DPR устройства.
  Масштаб равен выбранному 1, 2 или 3. Слишком большой bitmap отклоняется с сообщением,
  без незаметного уменьшения и обрезки.
- Windows: системное «Сохранить как», затем атомарная запись через существующий
  файловый адаптер в выбранную папку. Android: `ACTION_CREATE_DOCUMENT`, запись
  результата через ContentResolver без новых разрешений на общую память.
  Браузерный режим разработки скачивает Blob.
- Формат проекта не меняется. Экспорт — производный файл вне журналов проекта.

## Альтернативы

- Снимок текущего viewport: пропускает невидимые карточки и зависит от камеры.
- Свой Canvas-рендер каждого типа: дублирует оформление текста, таблиц и сущностей.

## Проверка

Юнит-тесты: состав выделения, колонки, связи, отрицательные координаты и предел bitmap.
Браузерный сценарий: PNG содержит текст и картинку вне экрана, размеры 1–3×,
прозрачность, светлая/тёмная тема; модальные окна блокируют команды фоновой доски.
